## 🎯 Objetivo do Curso

Este curso foi desenvolvido para capacitar profissionais em todas as áreas da Cybersecurity, desde conceitos básicos até técnicas avançadas de hacking ético, análise forense e competições CTF.

**Público-alvo**: Iniciantes, estudantes de TI, profissionais de segurança em transição

**Requisitos**: Conhecimento básico de redes, Linux e noções de programação
